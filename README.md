# MiniVR

Небольшая self-hosted платформа для просмотра VR-фотографий и создания виртуальных экскурсий.

## Возможности

- плоские изображения: Mono / Stereo SBS / Top-Bottom;
- панорамы 180° и 360°: Mono / SBS / Top-Bottom;
- desktop, mobile, Google Cardboard и WebXR-гарнитуры;
- VR HUD и управление взглядом (gaze);
- WebXR-контроллеры;
- экскурсии из нескольких сцен;
- визуальная расстановка hotspots;
- SQLite;
- локальный Three.js — CDN и внешний интернет для JS-библиотек не требуются.

## Требования

- PHP 8.2+;
- расширения PHP: PDO и SQLite/PDO_SQLite;
- веб-сервер Nginx или Apache;
- HTTPS для полноценной работы WebXR и датчиков браузера;
- право записи PHP-процесса в `data/` и `public/uploads/`.

Корень сайта (Document Root) должен указывать на каталог **`public/`**, а не на корень репозитория. Это не даёт веб-серверу напрямую раздавать `config.php`, SQLite и исходники из `src/`.

## Установка на Timeweb Cloud + FASTPANEL

1. Создайте сайт/домен в FASTPANEL.
2. Выберите PHP 8.2 или новее и PHP-FPM. В документации Timeweb для FASTPANEL режим PHP-FPM описан как Nginx + PHP-FPM; при нём правила `.htaccess` не используются.
3. Клонируйте проект, например:

```bash
cd /var/www
git clone https://github.com/asbcorp24/minivr.git
cd minivr
```

Если FASTPANEL создала другую директорию сайта, клонируйте проект туда либо укажите фактический путь в настройках сайта.

4. В настройках сайта установите корневую директорию сайта на:

```text
/путь/к/minivr/public
```

5. Проверьте SQLite:

```bash
php -m | grep -Ei 'sqlite|pdo'
```

На Ubuntu/Debian при отсутствии SQLite:

```bash
sudo apt update
sudo apt install php8.2-sqlite3
sudo systemctl restart php8.2-fpm
```

Если FASTPANEL использует другую версию PHP, замените `8.2` на фактическую.

6. Создайте каталоги и выдайте права PHP-процессу:

```bash
cd /путь/к/minivr
mkdir -p data public/uploads
sudo chown -R www-data:www-data data public/uploads
sudo chmod -R 775 data public/uploads
```

Имя пользователя PHP-FPM в панели может отличаться от `www-data`. В таком случае используйте пользователя сайта из FASTPANEL.

7. Измените логин и пароль администратора в `config.php` **до публикации сайта**:

```php
const ADMIN_USER = 'admin';
const ADMIN_PASSWORD = 'СЛОЖНЫЙ-ПАРОЛЬ';
```

Текущий пароль `change-me-now` предназначен только для первоначального запуска.

8. Подключите домен и включите SSL/HTTPS. Для WebXR HTTPS фактически обязателен в обычном браузерном использовании.

9. Откройте:

```text
https://ВАШ-ДОМЕН/
https://ВАШ-ДОМЕН/admin/
```

SQLite-файл `data/minivr.sqlite` создастся автоматически при первом обращении.

## Установка на чистый VPS Timeweb Cloud (Ubuntu + Nginx)

Установите пакеты:

```bash
sudo apt update
sudo apt install -y nginx git php8.2-fpm php8.2-cli php8.2-sqlite3
sudo mkdir -p /var/www
cd /var/www
sudo git clone https://github.com/asbcorp24/minivr.git
sudo chown -R $USER:www-data /var/www/minivr
cd /var/www/minivr
mkdir -p data public/uploads
sudo chown -R www-data:www-data data public/uploads
sudo chmod -R 775 data public/uploads
```

Пример Nginx:

```nginx
server {
    listen 80;
    server_name vr.example.ru;

    root /var/www/minivr/public;
    index index.php;

    client_max_body_size 200M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;
    }

    location ~ /\. {
        deny all;
    }
}
```

Активируйте сайт:

```bash
sudo ln -s /etc/nginx/sites-available/minivr /etc/nginx/sites-enabled/minivr
sudo nginx -t
sudo systemctl reload nginx
```

После этого настройте DNS домена на IP сервера и выпустите SSL-сертификат. Для загрузки больших SBS/360-фотографий увеличьте также `upload_max_filesize` и `post_max_size` в конфигурации используемого PHP-FPM, например до 200M.

## Обновление

```bash
cd /путь/к/minivr
git pull
```

База и загруженные изображения не находятся в Git, поэтому обычный `git pull` их не удаляет. Перед серьёзными обновлениями всё равно рекомендуется резервировать:

```text
data/minivr.sqlite
public/uploads/
```

## Первый запуск

1. Войдите в `/admin/`.
2. Загрузите VR-материалы и укажите формат: Flat / 180 / 360 и Mono / SBS / TB.
3. Создайте экскурсию.
4. Добавьте сцены и назначьте стартовую.
5. В разделе Hotspots расставьте переходы между сценами.
6. Проверьте экскурсию на desktop.
7. Проверьте Cardboard на телефоне через HTTPS.
8. Для Quest/Pico используйте кнопку VR в совместимом WebXR-браузере.

### Конструктор экскурсий

В `/admin/tours.php` откройте экскурсию:

- В **Конструкторе экскурсии** перетащите сцены мышью или поменяйте порядок стрелками (на телефоне), затем нажмите **Сохранить порядок**. Изменения не затрагивают идентификаторы сцен, интерактивные точки и озвучку.
- По кнопке **Настроить** откройте нужную сцену: здесь можно изменить название, длительность, направления взгляда, текст и аудио рассказа. Для изменений конкретной сцены используется отдельная кнопка **Сохранить сцену**.
- Внизу страницы найдите панораму по названию, выберите её по миниатюре и нажмите **Добавить сцену**. Одна панорама может участвовать в нескольких маршрутах.
- Кнопка ▶ рядом со сценой открывает её предпросмотр. Стартовую сцену, публикацию, обложку, ссылку прямого запуска и экспорт по-прежнему можно настроить в существующих блоках страницы.

Порядок сцен влияет на маршрут и автоматическое переключение в просмотрщике. Режимы просмотра Desktop, GYRO, Cardboard, WebXR и настройки параллакса не изменяются конструктором.

### Привязка информационных точек из JSON

В админке откройте **Привязка точек JSON** (`/admin/hotspot-import.php`). Загрузите JSON в формате `{"hotspots":[{"scene_id":72,"label":"...","content":"...","yaw":null,"pitch":null,"type":"info"}]}`. `scene_id` — идентификатор **сцены экскурсии**, а не панорамы. Страница показывает прогресс по сценам и предупреждает, если указанная сцена отсутствует в базе.

Выберите сцену и информационную точку справа, перетаскивайте панораму для обзора и **нажмите на место**, где должен появиться маркер. Можно поставить точку в центре взгляда или вручную скорректировать `yaw` и `pitch`. Нажмите **Сохранить координаты** для записи в таблицу `hotspots`. Не сохранённые точки с координатами `null` не публикуются. Просмотр панорамы поддерживает 360° Mono/SBS/TB; другие проекции не размещаются этим модулем.

JSON временно хранится в текущей сессии администратора. Повторная загрузка списка **не удаляет** существующие точки: записи с теми же `scene_id`, `type`, `label` и `content` обновляют координаты без дублей. При нескольких совпадениях сохранение блокируется до ручного исправления; другие точки сцены не затрагиваются. Кнопка «Очистить список» сбрасывает только временный список, не удаляя сохранённые позиции. Не загружайте JSON с произвольно проставленными координатами, если сначала хотите разместить метки визуально.

### Предзагрузка соседних панорам

После открытия сцены экскурсии просмотрщик заранее подготавливает до двух соседних сцен (следующую, предыдущую или следующую через одну). `scene-preloader.js` хранит HTML сцены и доступные сжатые ресурсы: изображение, карту глубины, маски; для больших тайловых панорам — манифест и базовые тайлы. При переходе готовые данные используются повторно, а при отсутствии кэша остаётся прежний способ загрузки.

Предзагрузка **не хранит дополнительную WebGL-геометрию или GPU-текстуры**. Память ограничена 12 МиБ на устройствах с сенсорным экраном и 32 МиБ на остальных, с LRU-очисткой и сроком хранения 2 минуты. Ненужные сетевые запросы отменяются при смене списка соседних сцен или скрытии вкладки. При включённой экономии трафика или очень медленной сети фоновая загрузка отключена. Математика параллакса, эффекты и режимы VR не изменяются.

### Тайлы и сферический параллакс по глубине

Для моно-панорам 360° с уже подготовленной тайловой пирамидой и картой глубины доступен общий режим: изображение загружается небольшими тайлами по мере поворота камеры, а их геометрия строится по **одному непрерывному сферическому полю глубины**. На соседних тайлах совпадают радиусы вершин на границах и замыкается шов 360°. Гибридный параллакс накладывает несколько полупрозрачных глубинных слоёв с общей небольшой текстурой-маской; исходная картинка остаётся фоном, не удаляется и не дорисовывается. Настройка качества параллакса ограничивает число слоёв. При переходе между сценами используются подготовленные манифест и базовые тайлы, прежние GPU-ресурсы освобождаются.

**Микродвижение листвы теперь совместимо с тайлами**: ручная PNG-маска 512×256 остаётся общей для панорамы, а без неё каждый JPEG-тайл получает небольшую автоматически вычисленную маску (до 128×128 пикселей). GPU-шейдер мягко смещает текстуру в двух ближних группах глубины, а по ручной маске — в указанных областях. На краях каждого тайла смещение затухает до нуля, что защищает шов 0°/360° и переходы уровней детализации. Маски создаются только для загруженных тайлов и освобождаются вместе с ними; полный исходный JPEG для анимации листвы не загружается. Сила, скорость и диагностические параметры `micro_motion_preview=1`, `micro_motion_mask=1`, `micro_motion=0` работают в обоих режимах.

Чтобы включился совмещённый тайловый рендерер, включите параллакс с картой глубины и **отключите** «Заполнение фона за ближними объектами», а также анимацию воды и контактные тени. Эти три эффекта пока требуют старого полноразмерного рендерера: он автоматически используется при их включении, при недоступной карте/тайлах или при ошибке загрузки. Для **новых** панорам экспериментальное заполнение фона по умолчанию выключено; уже сохранённые настройки не меняются. Без карты глубины обычная тайловая загрузка, включая микродвижение, продолжает работать. Стереопанорамы, 180°, плоские изображения, Cardboard, GYRO и WebXR сохраняют прежние способы управления и совместимые пути отображения.

### Параллакс при наклоне телефона

На телефоне при просмотре обычной моно-панорамы 360° с включённым параллаксом и загруженной картой глубины появляется отдельная кнопка **↔ 3D** над нижней панелью. Нажмите её, чтобы разрешить доступ к датчику ориентации и включить мягкое смещение точки обзора при небольших наклонах телефона. Повторное нажатие выключает эффект. Требуется HTTPS; на iPhone браузер отдельно запросит разрешение.

Это **имитация смещения** на основе наклона, а не настоящее отслеживание перемещения телефона в пространстве. В портретном положении эффект заметнее, но перемещение камеры ограничено, чтобы не разрушать ближнюю геометрию. Эффект сглажен и отключается при включении GYRO, Cardboard и WebXR. Без карты глубины кнопка не появляется; обычное управление панорамой сохраняется.

### GYRO на планшете и телефоне

В просмотрщике нажмите **GYRO** на странице HTTPS. На iPad Safari может отдельно запросить доступ к движению и ориентации. MiniVR ждёт первые корректные значения датчика до **6 секунд**, поддерживает события `deviceorientation` и `deviceorientationabsolute` и показывает сообщение прямо поверх панорамы, если доступ запрещён, браузер не предоставляет датчик или события приходят без углов. Кнопка **«Повторить попытку»** запускает новую проверку и новый запрос разрешения (если браузер позволяет его повторить). После разрешения поверните планшет, чтобы увидеть движение панорамы. Повторное нажатие GYRO выключает управление датчиком.

Отказ в разрешении может запоминаться самим браузером: в таком случае сначала разрешите датчики в настройках сайта/браузера. При неподвижном планшете браузер может временно переставать отправлять новые значения; MiniVR не отключает уже работающий GYRO только из-за отсутствия новых событий. Cardboard и WebXR используют собственные режимы управления и не зависят от этого ожидания.

## Структура

```text
config.php              конфигурация
src/db.php              SQLite и автоматические миграции
data/                   SQLite (не коммитится)
public/                  Document Root
public/admin/            админка
public/assets/           CSS/JS и локальные vendor-библиотеки
public/uploads/          загруженные изображения (не коммитятся)
```
