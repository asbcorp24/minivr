# Локальный кеш ИИ-моделей на Timeweb

Генерация выполняется **в браузере**. Timeweb отдаёт статические файлы модели, не запускает ИИ.

## Подготовка

На компьютере с Python 3.10+:

```bash
python -m pip install huggingface_hub
python scripts/download_ai_models.py
```

Скопируйте содержимое `public/assets/models/` на Timeweb в каталог сайта `public/assets/models/`, сохраняя подпапки.

- `/assets/models/onnx-community/depth-anything-v2-small/` — файлы Depth Anything V2 (конфигурация, препроцессор, ONNX и при наличии внешние данные).
- `/assets/models/deepfillv2_quantized.onnx` — модель DeepFill.

Проверьте, что файлы доступны по HTTPS и отдаются с HTTP 200 (а не страницей HTML). На виртуальном хостинге могут действовать ограничения на размер файла, дисковую квоту и отдачу больших файлов.

Если локальных файлов нет, браузер попробует загрузить удалённые модели. Для Depth Anything Transformers.js использует собственный механизм локального поиска и удалённый fallback; для DeepFill есть явный fallback.

**Важно:** DeepFill ONNX в текущем экспериментальном PR ещё не проверен на реальной модели: наличие файла, имена входов/выходов и размеры тензоров требуют проверки. Загрузка моделей на сервер не исправляет несовместимость самой модели.

Не добавляйте большие бинарные веса в Git: папка содержит .gitignore.
